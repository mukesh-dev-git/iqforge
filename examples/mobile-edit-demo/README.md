# IQForge mobile edit demo

This small Python application is a real end-to-end target for the IQForge Code screen.
Open `calculator.py` from **Code > Laptop files**, edit it on the phone, save it to the
laptop, and use **Run tests** to execute the repository test suite on the laptop.

Run this demo directly with:

```powershell
python examples/mobile-edit-demo/calculator.py
python -m pytest -q examples/mobile-edit-demo
```
